# Programação orientada a objetos — Mackenzie

Exercícios de Java desenvolvidos ao longo da disciplina. Cada pasta representa um exercício independente; **este repositório é um registro de aprendizagem**, não uma aplicação única.

## Conteúdo

- `Biblioteca/`: classes de livro, usuário e biblioteca; operações em listas.
- `ConcessionariaDeVeiculos/` e `GerenciadorDeVeiculos/`: herança e especialização de veículos.
- `Loja Digital/`: produtos físicos e digitais.
- `Sistema Avaliação de Restaurantes/`: classes abstratas e avaliações.
- `BancoDeDados/`: primeiro exercício com JDBC e SQLite.
- Arquivos na raiz: exercícios pontuais.

## Como explorar

Abra uma pasta e leia as classes e o `Main.java` quando houver. Alguns exercícios dependem de bibliotecas externas ou precisam de ajustes antes de rodar; ainda não há build Maven único nem testes automatizados.

## Melhorias planejadas

- Corrigir casos de lista vazia, média de avaliações e seleção do melhor restaurante.
- Acrescentar testes JUnit aos exercícios principais.
- Organizar cada exercício executável com instruções próprias.
- Separar exercícios acadêmicos de projetos completos de portfólio.

Este repositório mostra meu progresso em POO; os projetos de backend completos terão repositórios próprios.
